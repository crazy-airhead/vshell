# vShell SSH客户端管理软件 — 用户手册

## 一、安装说明

### 1.1 系统要求

- macOS 12.0（Monterey）或更高版本
- Intel处理器（x86_64）或Apple Silicon（ARM64/M系列芯片）
- 至少4GB可用内存
- 至少500MB可用硬盘空间
- 网络连接（用于SSH连接远程服务器）

### 1.2 安装步骤

1. 下载vShell安装包（.dmg或.app文件）
2. 双击打开安装包
3. 将vShell.app拖入Applications文件夹
4. 首次打开时，系统可能提示安全性确认，请在"系统偏好设置 → 安全性与隐私"中允许vShell运行

### 1.3 卸载

1. 退出vShell应用
2. 将vShell.app从Applications文件夹移至废纸篓
3. （可选）删除数据目录：`~/Library/Application Support/vshell/`

## 二、快速入门

### 2.1 启动应用

在Applications文件夹中双击vShell图标启动应用。应用启动后将显示主界面窗口。

### 2.2 创建第一个SSH连接

1. 在左侧边栏中，点击"+"按钮或右键选择"新建连接"
2. 在弹出的连接表单中填写以下信息：
   - **名称**: 连接的显示名称（如"生产服务器"）
   - **主机**: 服务器的IP地址或域名
   - **端口**: SSH端口（默认为22）
   - **用户名**: SSH登录用户名
   - **认证方式**: 选择"密码"或"私钥"
   - **密码/私钥**: 根据认证方式填写对应信息
3. 点击"保存"完成连接创建

### 2.3 连接到服务器

1. 在左侧连接树中，双击目标连接
2. 应用将在主区域打开新的终端标签页
3. 等待连接建立，终端将显示远程服务器的Shell提示符

### 2.4 断开连接

- 关闭终端标签页即可断开当前会话
- 当所有会话关闭后，底层SSH连接将自动断开

## 三、功能详解

### 3.1 连接管理

#### 3.1.1 连接分组

- 右键侧边栏空白区域，选择"新建分组"
- 输入分组名称
- 将连接拖拽到对应的分组下

#### 3.1.2 编辑连接

- 右键目标连接，选择"编辑"
- 修改连接信息后点击"保存"

#### 3.1.3 删除连接

- 右键目标连接，选择"删除"
- 确认删除操作

#### 3.1.4 连接排序

- 通过拖拽调整连接顺序
- 排序信息自动保存

#### 3.1.5 认证方式

vShell支持以下认证方式：

| 认证方式     | 说明                            |
| -------- | ----------------------------- |
| **密码认证** | 使用用户名和密码登录，密码经AES-256-GCM加密存储 |
| **私钥认证** | 使用SSH私钥文件登录，支持带密码保护的私钥        |
| **键盘交互** | 适用于需要二次认证的场景                  |

### 3.2 终端操作

#### 3.2.1 多标签终端

- 每个连接可打开多个终端标签
- 点击标签切换不同的终端会话
- 支持标签关闭（Ctrl+W 或 Command+W）

#### 3.2.2 终端交互

- 直接在终端中键入命令
- 支持复制（Ctrl+C / Command+C）、粘贴（Ctrl+V / Command+V）
- 支持窗口大小自适应调整

#### 3.2.3 快速命令

- 支持配置常用命令快捷执行
- 在连接上右键可查看快速命令列表

### 3.3 文件管理（SFTP）

#### 3.3.1 打开SFTP面板

- 连接服务器后，点击底部SFTP面板标签
- 或从菜单/工具栏打开SFTP面板

#### 3.3.2 浏览远程文件

- 左侧显示远程目录树，点击展开子目录
- 右侧显示当前目录的文件列表
- 支持文件大小、修改时间、权限等信息展示

#### 3.3.3 文件上传

- 方式一：将本地文件拖放到远程目录区域
- 方式二：在SFTP面板中点击上传按钮，选择本地文件
- 上传进度实时显示

#### 3.3.4 文件下载

- 选择远程文件，点击下载按钮
- 选择本地保存路径
- 下载进度实时显示

#### 3.3.5 本地文件浏览

- SFTP面板的本地文件树支持浏览本地文件系统
- 支持从本地文件树拖拽文件到远程

### 3.4 服务器监控

#### 3.4.1 打开监控面板

- 连接服务器后，点击监控面板标签
- 监控数据自动开始采集

#### 3.4.2 监控指标

| 指标         | 说明              |
| ---------- | --------------- |
| **CPU使用率** | 实时显示服务器CPU使用百分比 |
| **内存使用**   | 显示已用/总内存量及使用率   |
| **磁盘使用**   | 显示各挂载点的磁盘使用情况   |
| **网络流量**   | 显示网络接口的收发速率     |

#### 3.4.3 图表交互

- 图表支持鼠标悬停查看详细数据
- 支持时间范围缩放

### 3.5 端口转发

#### 3.5.1 创建端口转发

1. 在连接属性中添加端口转发规则
2. 配置以下参数：
   - **本地地址**: 本地监听的IP和端口
   - **远程地址**: 通过SSH隧道访问的远程IP和端口
3. 保存后端口转发自动生效

#### 3.5.2 管理转发规则

- 在连接属性中查看/编辑/删除已有的端口转发规则
- 断开连接时所有转发规则自动停止

### 3.6 远程文件编辑

#### 3.6.1 打开文件编辑器

1. 在SFTP面板中右键远程文件
2. 选择"编辑"
3. 文件内容将在Monaco Editor中打开

#### 3.6.2 编辑与保存

- 编辑器支持语法高亮（根据文件扩展名自动识别）
- 支持查找/替换（Ctrl+F / Command+F）
- 按Ctrl+S / Command+S保存文件到远程服务器
- 关闭编辑器标签放弃未保存的更改

### 3.7 SSH密钥管理

#### 3.7.1 密钥管理面板

- 通过菜单栏"设置" → "密钥管理"进入

#### 3.7.2 导入私钥

1. 点击"导入"按钮
2. 选择本地私钥文件（如 id_rsa、id_ecdsa 等）
3. 如有密码短语，输入对应的密码短语
4. 私钥将加密后存入数据库

#### 3.7.3 生成密钥对

1. 点击"生成"按钮
2. 选择密钥类型（ECDSA / Ed25519 / RSA）
3. 可选设置密码短语
4. 生成后自动保存私钥，导出公钥

#### 3.7.4 在连接中使用私钥

- 创建/编辑连接时，认证方式选择"私钥"
- 从已保存的私钥列表中选择目标私钥

### 3.8 SSH配置管理

#### 3.8.1 导入SSH配置

1. 打开SSH配置面板
2. 点击"导入"按钮
3. 选择 `~/.ssh/config` 文件
4. 系统解析配置并展示可导入的连接条目
5. 选择需要的条目导入为vShell连接

#### 3.8.2 导出为SSH配置

1. 在SSH配置面板中选择连接
2. 点击"导出"
3. 系统生成标准SSH配置格式内容
4. 可保存到 `~/.ssh/config` 文件

- 菜单栏：vShell → Settings... 或按 `Cmd/Ctrl + ,`

## 六、常见问题

### Q: 连接失败怎么办？

1. 检查服务器地址和端口是否正确
2. 检查用户名和密码/私钥是否正确
3. 确认网络可连通目标服务器（可通过ping测试）
4. 确认目标服务器的SSH服务正在运行

### Q: 终端显示乱码？

1. 确认远程服务器的语言环境设置（LANG=en_US.UTF-8 或 LANG=zh_CN.UTF-8）
2. 在vShell设置中调整终端字体为支持中文的等宽字体

### Q: 文件传输速度慢？

1. 文件传输速度受网络带宽限制
2. SFTP协议本身的加密传输会有一定开销
3. 小文件传输比大批量小文件传输效率更高

### Q: 如何备份连接数据？

将以下目录备份即可：`~/Library/Application Support/vshell/`
该目录下的 `vshell.db` 文件包含所有连接配置信息。
