## 功能概述

vShell是一款基于Go语言和Vue 3框架开发的桌面端SSH客户端管理工具，主要提供以下功能：

1. SSH连接管理与终端会话
2. SFTP文件传输与管理
3. 本地端口转发
4. 服务器资源监控
5. 远程文件编辑
6. SSH密钥管理
7. SSH配置文件导入导出
8. 快速命令执行

## 技术架构

- **后端框架**: Wails 3 (Go)
- **前端框架**: Vue 3 + TypeScript + Naive UI
- **终端引擎**: xterm.js
- **代码编辑器**: Monaco Editor
- **数据库**: SQLite
- **加密方案**: AES-256-GCM
- **SSH协议**: golang.org/x/crypto/ssh
- **桌面框架**: Wails 3.0.0
