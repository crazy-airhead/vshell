## 功能概述

vShell是一款基于Go语言和Vue 3框架开发的桌面端SSH客户端管理工具，面向运维人员和开发者，提供安全、高效的远程服务器管理能力。软件为纯本地应用，无云端组件，所有数据存储在用户本地计算机中，保障用户数据的私密性和安全性。主要功能模块如下：

1. **SSH连接管理与终端会话**：支持密码认证、私钥认证和键盘交互等多种认证方式，用户可通过分组管理、拖拽排序等方式组织连接列表。终端基于xterm.js实现完整终端模拟，支持256色显示和xterm-256color伪终端，支持多标签页同时操作，窗口大小动态调整。终端数据通过事件驱动机制实现高性能实时传输，输出缓冲优化确保流畅的交互体验。

2. **SFTP文件传输与管理**：提供可视化的远程文件浏览器，支持目录浏览、文件上传与下载、拖拽传输等功能。内置并发传输池（3个并发任务），支持实时传输进度跟踪。本地与远程文件树双面板布局，方便用户跨系统管理文件。

3. **本地端口转发**：支持通过SSH隧道建立本地端口转发，将本地端口映射到远程服务器目标地址，实现安全的网络访问。转发规则可动态创建和关闭，断开SSH连接时自动清理。

4. **服务器资源监控**：复用已有SSH连接，通过读取/proc/stat、/proc/meminfo等系统文件，实时采集CPU使用率、内存使用量、磁盘使用率和网络流量等关键指标，并以ECharts图表形式直观展示，帮助运维人员快速掌握服务器运行状态。

5. **远程文件编辑**：集成Monaco Editor代码编辑器，支持直接在应用内打开远程服务器上的文件进行编辑。支持语法高亮、查找替换等编辑功能，编辑完成后一键保存到远程服务器，无需额外下载上传操作。

6. **SSH密钥管理**：提供独立的密钥管理面板，支持导入已有私钥（如id_rsa、id_ecdsa等）和在线生成新密钥对（支持ECDSA、Ed25519、RSA算法），私钥数据经AES-256-GCM加密后存储在本地数据库中，创建连接时可直接选用已保存的密钥。

7. **SSH配置文件导入导出**：支持解析标准~/.ssh/config文件，将已有SSH配置条目批量导入为vShell连接；也支持将vShell中管理的连接导出为标准SSH配置格式，方便与命令行工具协作使用。

8. **快速命令执行**：支持配置常用命令模板，在终端会话中快速调用执行，减少重复输入，提高运维效率。

9. **国际化支持**：内置中文和英文双语言界面，基于vue-i18n框架实现，满足不同语言用户的使用需求。

## 技术架构

- **后端框架**: Wails 3 (Go)
- **前端框架**: Vue 3 + TypeScript + Naive UI
- **终端引擎**: xterm.js
- **代码编辑器**: Monaco Editor
- **数据库**: SQLite
- **加密方案**: AES-256-GCM
- **SSH协议**: golang.org/x/crypto/ssh
- **桌面框架**: Wails 3.0.0
