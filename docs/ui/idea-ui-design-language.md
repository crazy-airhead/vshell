## 1. 设计哲学：十条核心原则

从 IntelliJ 平台 UI 代码的组织方式中，可以提炼出以下设计语言内核：

1. **工具优先，内容至上**。IDE 的「铬框」（工具栏、边栏、状态栏）永远比内容更低調：灰阶为主体、小字号、高密度。视觉焦点留给编辑器内容。
2. **一切皆 Token，主题即数据**。颜色、尺寸、边框、圆角、图标全部定义为键值对（theme JSON → UIManager defaults），组件代码只消费 token，从不硬编码颜色。这使得「亮/暗主题」「紧凑模式」「高对比度」成为纯数据切换。
3. **灰阶为主体，单一品牌色为强调色**。整个界面只有一种品牌蓝作为 accent（expUI：`#3574F0`，明暗通用）。彩色只用于：默认按钮、选中态、焦点、链接、语义状态（错误/警告/成功）和 VCS 状态。
4. **用「分层背景」表达层级，而非阴影**。背景色由深（窗口）到浅（弹出层/编辑区）分层（Islands 主题将其显式命名为 `layer-0/1/2`），配合 1px 边框，几乎不使用投影做层级（阴影仅用于真正的浮动窗口：弹窗、通知、无装饰对话框）。
5. **1px 边框 + 低透明度叠加做交互反馈**。悬停/按下多用极低透明度的前景叠加：暗色主题下统一是白色低透明覆盖（`#FFFFFF1A` ≈ 10% 悬停、`#FFFFFF26` ≈ 15% 按下），亮色下用色板中相邻的浅灰或浅蓝。
6. **克制的圆角阶梯**：4（tooltip）→ 6（经典控件）→ 8（按钮/输入/弹出/选中背景，新 UI 的主力值）→ 12（横幅/通知气泡/工具栏悬停）→ 20（Islands 的「岛」容器）。高对比度主题全部归零。
7. **状态语义完整覆盖**。每个交互元素都有完整状态集：default / hover / pressed / selected(+inactive) / focused / disabled(+边框独立 token)，且选中态还有「非激活窗口」的降级版本（inactive），失焦时不丢失选中信息。
8. **明暗同构**。明暗主题使用同一套 token 名与组件结构，只是值成对替换；连色板编号都设计为「镜像」（见 3.1）。
9. **一切随缩放**。所有度量经过统一缩放管道（`JBUI.scale`），字体放大即整体放大；紧凑模式（`.compact` 后缀键）是同一套 token 的密度变体，不是另一套设计。
10. **键盘优先**。处处有速度搜索（Speed Search）、无处不在的双 Shift 搜索、完整快捷键体系；悬停只是快捷方式的补充而非唯一入口。

## 2. 主题系统架构

### 2.1 三代 UI

| 代际            | 主题文件                                                 | targetUi | 状态                   |
| ------------- | ---------------------------------------------------- | -------- | -------------------- |
| 经典 UI         | `intellijlaf.theme.json` / `darcula.theme.json`      | classic  | 维护模式                 |
| New UI（实验→正式） | `expUI_light.theme.json` / `expUI_dark.theme.json` 等 | new      | 本文档主要数据源             |
| Islands（当前默认） | `islands/ManyIslandsLight/Dark/Darcula.theme.json`   | islands  | 最新默认主题，引入命名式语义 token |

继承链示例：`ManyIslandsLight → expUI_light_with_light_header → expUI_light → intellijlaf`。子主题只覆盖差异键。

### 2.2 theme.json 结构

```jsonc
{
  "name": "Light", "author": "...", "dark": false,
  "parentTheme": "ExperimentalLight",       // 继承
  "editorScheme": "Light",                  // 关联的编辑器配色方案（独立体系，见第 8 章）
  "colors":  { "Gray1": "#000000", ... },   // 色板：命名颜色（仅数据，不直接生效）
  "ui":      { "*": {...}, "Button": {...} },  // UI 映射：token → 值
  "icons":   { "old.svg": "new.svg", "ColorPalette": {...} }  // 图标替换与着色
}
```

关键机制（`UIThemeBean.readTheme()` / `UITheme.applyTheme()`）：

- **扁平化**：嵌套对象 `"Editor": {"SearchField": {...}}` 被展平为 `Editor.SearchField.x`。
- **通配符**：`ui` 下的 `"*"` 键（如 `"*.background"`、`"*.selectionBackground"`）会应用到**所有**以此后缀结尾的 UIManager 键上——这是「全局语义 token」的实现方式。
- **值解析约定**（`uiThemeParser.kt`）：
  - `"t,l,b,r"` → Insets；`"w,h"` → Dimension；数字 → 宽/高；
  - `*Border` → 边框类名（反射加载）、颜色（1px 线）或 `"t,l,b,r,#hex"`；
  - `#RRGGBB[AA]` → 颜色（**透明度内联在 hex 第 7-8 位**，如 `#3574F029` ≈ 16% 蓝）；
  - `*.svg` → 图标；`AllIcons.X.Y` → 反射图标。
- **密度变体**：任意键可加 `.compact` 后缀（`Button.minimumSize.compact`），紧凑模式生效，解析前剥离后缀。
- **平台分支**：值可写成 `{"os.default": …, "os.windows": …, "os.mac": …}`。
- **字体不在主题里**：字体族与基准字号由 `LafManagerImpl` 注入（Inter 13），主题只控制相对偏移（`*.fontSizeOffset`）。

### 2.3 两个独立的配色体系

1. **UI 主题**（theme.json）→ 界面铬框的颜色；
2. **编辑器配色方案**（color scheme XML，如 `expUI_lightScheme.xml` / `expUI_darkScheme.xml`）→ 文本编辑区的语法与标记颜色。

两者通过主题的 `editorScheme` 字段关联，但结构、键名、定制入口完全独立。**设计自己的编辑器时强烈建议沿用这种分离**——用户对「界面主题」和「代码配色」的定制期望是不同的。

### 2.4 元数据与可定制性

平台为 869 个 UI 键提供了带描述的元数据（`themes/metadata/IntelliJPlatform.themeMetadata.json`），供主题定制 UI 使用。启示：**设计系统应自带一份「token 字典」**（名称、描述、since/废弃版本），而不仅是裸值。

## 3. 色彩系统

### 3.1 色板构建法则

每个色相 10~14 级渐进步进。**编号语义在明暗主题间镜像**：

- 亮色主题：低编号 = 深（文字/描边），高编号 = 浅（填充/背景）；
- 暗色主题：低编号 = 深（填充/背景），高编号 = 浅（文字/描边）。

因此「Gray6」在亮色下是图标配色主灰 `#6C707E`（深），在暗色下是 `#5A5D63`（深填充）——**编号表达的是「在这个主题里的深浅角色」，不是绝对明度**。这是让两套主题共享键名的关键技巧。

- **暗色悬停叠加**：工具栏图标按钮统一 `ActionButton.hoverBackground = #FFFFFF16`（≈9%）、按下 `#FFFFFF26`（≈15%）；主工具栏悬停 `#FFFFFF1A`（10%）。亮色没有等价的黑叠加，直接用色板浅灰/浅蓝。
- **输入控件边框**比分隔线强：`Component.borderColor` = L `#C9CCD6` / D `#4E5157`；聚焦时变为 `Component.focusedBorderColor` = L `#FFFFFF`+外圈焦点环 / D `#2B2D30`+焦点环。
- **窗口级 1px 外框**：`Window.undecorated.border = 1,1,1,1,#5A5D6B`（亮）/ `#5A5D63`（暗）。

### 3.4 accent（品牌蓝）的使用位置

`#3574F0` 只出现在：默认按钮填充、焦点环（2px）、选中下划线、工具窗按钮选中背景、进度条、链接边框（注意：**链接文字本身用更深/更浅的 Blue2/Blue9，不是纯 accent**）、拖拽指示。原则：**accent 是「当前态/可激活」的颜色，不是装饰色**。

- **字号阶梯**（相对 label 基准的偏移，`JBFont`）：

| 级       | 偏移       | 实际字号（基准 13） | 字重      | 用途         |
| ------- | -------- | ----------- | ------- | ---------- |

| regular | 0        | 13          | regular | 正文/控件      |
| medium  | −1       | 12          | regular | 辅助         |
| small   | −2       | 11          | regular | 广告行/标签辅助   |
| mini    | −4（下限 9） | 9–11        | regular | 极小标注       |

- **字体族**：JetBrains Mono；回退 Windows Consolas / macOS Menlo / Linux DejaVu Sans Mono / Monospaced。

## 5. 度量、间距与缩放

### 5.1 缩放模型

```
最终像素 = JBUI.scale(v) = round(v × userScaleFactor)
pixScale = systemScaleFactor × userScaleFactor   （JRE-HiDPI 模式下）
```

- 用户缩放离散化为 **0.25 步进**；Linux 1.25 特殊回退 1.0。
- 所有尺寸/内边距/图标都过这个管道；**设计稿只需给逻辑像素**。

### 6.2 硬规则（源码机器校验 enforced）

1. **明暗成对**：每个图标必有 `_dark` 孪生，**几何完全相同**，只换颜色。
2. **只允许调色板色**：SVG 中只能出现 3.8 表中的颜色（以及少量节点背景色如 `#E7EFFD`）。
3. **禁止** `currentColor`、`<style>`、渐变、滤镜（expui 全目录零命中）。
4. 根元素 `fill="none"`；默认 `stroke-width="1"`；徽章主字形可用 1.5/2。
5. **像素网格**：描边落在 `.5` 中心线上保证锐利。
6. **安全留白**：16 画布留 1px、20 画布留 2px keep-out。
7. 文件名 camelCase；第一行 Apache 协议头。
8. 机器校验：`icon-robots.txt`（skip/deprecated/merge 指令）+ `*IconMappings.json`（新旧映射，平台主表 666 条）+ `ImageSanityChecker`（ retina/暗色完整性、异常尺寸）。

### 6.4 状态着色机制

- **主题换色**：加载 SVG 时按「精确颜色字符串替换」打补丁（`SvgAttributePatcher`），缓存以补丁摘要为键——这是「无 currentColor 也能换肤」的实现。
- **选中态反色**：选中（深色底）时把灰对映射为白（`iconColorsOnSelection` / `toStrokeIcon`），如 `#6C707E → #FFFFFF`。
- **禁用态**：由渲染器按灰度规则绘制，不换图标文件。

| Tooltip 自动消失     | 10s（单行）/ 30s（多行）                            |
| 模态进度出现延迟         | 300ms                                       |
| Indeterminate 进度 | 周期 800ms、重绘 50ms                            |
| 光标闪烁             | 500ms                                       |
| 标签选中滑动动画         | 默认**关**（registry 可开）                        |
| 记录指示             | 250ms/帧                                     |

原则：动效只用于「出现/消失」的过渡，不用于持续的装饰；时长偏快（125–300ms），绝不阻塞输入。

## 12. 交互模型与导航体系（UE）

> 数据源：`platform/platform-resources/src/keymaps/$default.xml`（基准键位）、`Mac OS X 10.5+.xml`（约 230 个 mac 例外）、速度搜索/切换器/Search Everywhere 实现类。

### 12.1 三条交互通道与平台映射

- **键盘是一等公民**：任何功能都有快捷键或可通过命令面板到达；悬停只是补充。
- **鼠标等价完备**：导航类动作同时绑定鼠标（后退/前进 = 鼠标侧键 4/5；跳转声明 = ⌘/Ctrl+点击、mac 还支持 Force-touch 与中键）。
- **修饰键双击是「手势」而非按键**：双 Shift（Search Everywhere）、双 Ctrl（Run Anything）走独立的手势分发通道（`ModifierKeyDoubleClickHandler`，时序专门调优）。
- **macOS 映射是计算出来的**：继承自基准键位的快捷键自动把 Ctrl⇄⌘ 互换；mac 配置文件只显式声明例外；空的 `<action id="X"/>` 元素表示清除继承。

### 12.2 Action 系统：交互的单一事实来源

- **一切交互皆命令**（AnAction）：菜单项、工具栏按钮、快捷键、命令面板（Find Action）、Keymap 设置消费同一注册表。设计含义：**为每个功能定义稳定命令 id + text + description + icon**，菜单/按钮/快捷键/无障碍标签全部从它派生。
- `text` → 菜单/按钮标签 + 无障碍名；`description` → tooltip + 无障碍描述。
- **同义词机制**（`<synonym>`）：一个命令多个可搜索名称（如 Annotate/Blame、「进入/退出免打扰」两种说法），使命令面板按用户直觉匹配。
- **无默认快捷键 ≠ 不存在**：Annotate、分屏、克隆光标、专注模式等均无默认键位，靠 Find Action 可达——「可发现性优先于快捷键绑定」。

### 12.4 速度搜索（Speed Search）：输入即过滤

任何**列表型 UI**（树、列表、表格、弹出菜单）都支持直接输入过滤：

- **激活**：组件内直接敲字母/数字（含部分标点），或 Ctrl+F（SpeedSearch 动作）；IME 输入同样支持。
- **匹配算法**：非连续子串 + camelHumps 感知；**无匹配时输入框文字变红**（错误前景色）。
- **过滤内导航**：↑/↓/Home/End 在命中项间移动；Ctrl+Backspace 删除查询最后一个词。
- **退出**：Esc 关闭（并消费事件）；Enter/翻页键提交选择；焦点丢失/工具窗失活自动关闭。
- **高亮**：由渲染器显式调用（命中片段加「搜索匹配」背景样式，保留原前景色）。
- **设计准则**：文件树、变更列表、分支列表、命令面板……凡列表必有速度搜索。这是 IDEA「键盘优先」最核心的落地面。

### 12.5 Recent Files / Switcher / Recent Locations

三者共用同一组件（`Switcher`），行为差异是产品决策的范本：

|             | Switcher（Ctrl+Tab） | Recent Files（Ctrl+E） |
| ----------- | ------------------ | -------------------- |
| 生命周期        | **瞬态**：松开修饰键即关闭    | **固定**：可调大小、记住尺寸     |
| 数据源         | 标签选择历史（上限 30）      | 最近文件 + 已打开文件合并       |
| 「仅显示已修改」复选框 | 无                  | 有（弹窗打开时再按 Ctrl+E 切换） |
| 工具窗栏        | 有，Alt+N 助记         | 有，外加「最近位置」入口         |
| 多选          | 不支持                | 支持                   |

- **Recent Locations（Ctrl+Shift+E）**：记录的是**光标位置**（带 range marker，上限 25），每行显示「文件 + 面包屑路径 + 该行内容」——比「最近文件」更细一级的历史。
- 屏幕阅读器激活时禁用 Ctrl+Tab 切换器（该键被让给焦点遍历）——无障碍优先于效率功能。

### 12.6 Search Everywhere（双 Shift）

- 结果分组与排序权重：Top Hit(50) → Recent Files(70) → Classes(100) → Files(200) → Symbols(300) → Actions(400) → …（权重小者靠前）。
- **输入防抖 100ms**（空输入为 0）；单贡献者 tab 上限 30 条，多贡献者每源 15 条（All tab 强制 30）。
- `@` 命令前缀把结果过滤到单一类别（如 `@run`、`@actions`）；Tab/Shift+Tab 切组。
- Tab/Enter 提交；PgUp/PgDn 在组间跳转。

### 12.7 模态谱系与 Esc 语义

交互面的「打断程度」从低到高：

```
悬停预览 < 瞬态弹出(松键即走) < 固定弹出 < 工具窗(非模态) < 模态进度(≥300ms 才出现) < 模态对话框
```

- 能用左边就不用右边：**非模态倾向**是平台的一贯选择（非模态提交、后台任务、通知）。
- **Esc 级联语义**（固定顺序）：先关速度搜索 → 再关弹出/查找栏 → 再清除搜索高亮 → 再把多光标收敛为单光标。一次 Esc 只退一层。

### 12.8 选择与多光标

- Ctrl+W 不是「选单词」而是**沿语法层级向外扩展**（token → 词 → 表达式 → 语句 → 段落…），Shift+Ctrl+W 向内回退。
- 多光标入口**鼠标优先**（Alt+Shift+Click）；键盘侧 Alt+J 逐个追加出现、Ctrl+Alt+Shift+J 全部出现。
- 「克隆光标到上/下一行」无默认键位，仅命令面板可达——高频留给用户自定义，低频不占键位。

### 12.9 直接操作（拖放）

- **拖编辑器标签出标签栏** → 分裂编辑器 / 浮动窗口 / 停靠为工具窗（拖动时预选将保留的标签）。
- **拖文件进编辑器** → 按 provider 决定打开/插入路径/插入内容；拖到分割条上 = 打开。
- **拖工具窗条按钮** → 换边、重排。
- 设计准则：拖放是快捷方式，**每个拖放目标都必须有等价的菜单/命令入口**。

### 12.10 键位设计的元规则（从键位表归纳）

1. Ctrl+K/Ctrl+T/Ctrl+D 等「字母键」给**高频工作流动词**（Commit/Update/Diff）。
2. Ctrl+Shift+同字母 = 该动词的「推/强」变体（Ctrl+K 提交 → Ctrl+Shift+K 推送；Ctrl+Alt+←/→ 导航 → …）。
3. Alt+数字 = 工具窗；Alt+` = VCS 弹窗；Ctrl+Shift+` = 分支。
4. Shift+Enter 永远是「不破坏当前行的换行/在旁边打开」。
5. F 键族（F2 错误、F7 diff、F11 书签、F12 大纲/隐藏工具窗）保持跨平台一致。
6. 一个快捷键可按上下文复用（Ctrl+E 在弹窗开/关时含义不同），但必须**上下文可预期**。

### 13.2 进度反馈三级模型

| 级别       | 形态                                     | 规则                                     |
| -------- | -------------------------------------- | -------------------------------------- |
| 1. 状态栏内联 | 单个紧凑指示器 + 文本；多任务显示「显示 N 个进程」链接，点击开进程弹窗 | 默认级别；支持暂停/恢复/取消；面板悬停可出结果气泡             |
| 2. 后台任务  | 无对话框，仅状态栏                              | `Backgroundable` 的默认；可从模态点「后台」降级到此     |
| 3. 模态对话框 | 取消 + 后台两个按钮；Esc = 取消（仅无修饰键）；结束后焦点归还原组件 | **300ms 后才显示**；不可取消段内禁用取消按钮（10ms 节流刷新） |

- **不确定 → 确定优先**：只有拿到 fraction 才画进度条，否则画动画条；省电模式暂停动画。
- 设计准则：**进度是承诺，不是装饰**——宁可内联也别抢模态；宁可 300ms 无反馈也别闪一下。

### 13.3 通知分级与路由

| 显示类型             | 行为                     |
| ---------------- | ---------------------- |
| `NONE`           | 不弹，仅进日志                |
| `BALLOON`        | 气泡，**10s** 智能淡出        |
| `STICKY_BALLOON` | 需手动关闭（5min 兜底）         |
| `TOOL_WINDOW`    | 在工具窗内显示；不可用时回退 BALLOON |

- **按组（Group）注册**：每组声明默认显示类型 + 是否入日志；未注册的组运行时按 BALLOON 兜底。用户可按组改设置——**通知的粒度单位是「组」，不是单条**。
- 气泡内容折叠为 4 行（可展开至 10 行、最大宽 600）；动作 >2 个折叠进「更多」；同组气泡合并为「组内还有 N 条」。
- 项目启动早期通知排队，直到启动完成才展示。
- 没有「免打扰」总开关——用组级 NONE + 全局气泡开关表达。
- **致命错误**独立通道：状态栏红色感叹图标（未读时闪烁），池上限 100 条，点击开错误对话框；这是唯一「必须点击处理」的通知。

### 13.4 对话框 UX 规则

- 键：**Esc = 取消**、F1 = 帮助、Enter = 默认按钮、←/→ 在按钮间移动、Y/N 助记。
- **校验内联**：错误显示在目标控件旁（ValidationInfo 携带目标组件）；警告可保持 OK 可用。
- **「不再询问」**（DoNotAskOption）：默认不勾选；记住的选择仅在用户点了确认按钮时保存（点取消不保存）。
- 尺寸四档、按钮栏右下、按钮间距 12（见 7.11）。
- 元规则：**可撤销的操作不要用对话框确认**——用撤销当安全网；对话框只留给「不可撤销且必须二选一」的决策；能用通知/内联就不用对话框。

### 13.5 撤销与安全网

- 文档撤销栈 100 步、跨文件命令撤销 10 步；撤销会与外部修改冲突时才弹确认。
- **Local History（本地历史）**：文件保存/创建/删除/重命名自动快照；**VCS 关键操作前后自动打标签**（update 前/后、patch 应用、回滚、commit（带提交信息标签））→ 任何文件可回滚到任意时点，与 Git 无关。这是「Git 之外的第二张安全网」。
- **Shelve**：把未提交改动存为补丁（带描述），随时恢复。
- **变更列表（changelist）**：活动列表概念；提交信息自动保存在列表上、切回时恢复。

### 13.6 Git 工作流 UX（源码行为）

1. **非模态提交**：Git（分布式 VCS）默认用 Commit 工具窗而非对话框——复选框勾选文件（支持部分提交）、提交信息编辑器（模板/历史补全）、**Commit 是该面板的默认按钮**（Enter 即提交）、Amend 开关、「Commit and Push…」合并动作；提交结果用通知回报。
2. **gutter 修改标记交互**：悬停出 tooltip；**单击标记区**弹出该行的迷你 diff 卡（编辑器片段 + 工具栏：查看范围 diff、复制原内容、上一处/下一处变更、词级高亮开关、**回滚此行** Ctrl+Alt+Z）；同源的错误条纹上画细标记（100ms 防抖）。
3. **diff 导航**：F7/Shift+F7 下一处/上一处差异；Ctrl+Alt+Shift+↓/↑ 在文件内变更块间跳。
4. **合并冲突解决器**：三栏；动作 = 应用左侧/右侧、**用某侧解决**、忽略某侧、全部忽略、**重置该决定**（可反悔）、尽量自动解决。
5. **分支弹窗**：树形 + 搜索框（带速度搜索）；分区 = 当前 / **最近分支（自动展开）** / 本地 / 远程 / 标签；**空格键收藏**分支；记住尺寸与展开态。
6. **Annotate**：无默认键位；gutter 注释列（作者/日期/revision）；着色模式可切（按作者/按版本/无）。
7. 提交/更新/push 的进度一律走 13.2 的三级模型。

### 13.7 编辑器微观交互

- **折叠箭头仅悬停显示**；悬停折叠锚点弹出「隐藏内容预览」浮层（最少 2 行）；点击锚点切换折叠。
- **粘性行**：点击行即把光标放到该行；可按语言开关/配置/禁用。
- **面包屑**：点击导航；Shift/⌘+点击带选区导航。
- **错误条纹**：悬停标记出 tooltip；**点击标记跳到该错误**；F2/Shift+F2 顺序遍历。
- **内联提示**：可悬停/点击；全局与逐提供者两级开关。
- **补全自动弹出**默认开（无固定延迟键）；参数信息 1s、quick doc 500ms。
- **自动滚动**（树↔编辑器双向）默认**关**——避免大项目里树频繁跳动；临时放行用「ALLOW_ONCE」。
- 多光标时 Esc 先收敛为单光标（再按才走清高亮层级）。

### 13.8 空状态 / 加载状态 / 首次使用

- **空编辑器 = 富空状态**：可渲染服务驱动的内容（预算 1s，降级版 100ms），显示快捷键提示与「拖文件到此处」；空状态可获得焦点（Esc 到达）。
- **欢迎页**是首启与无项目时的家（通知也能在其上显示）。
- **GotIt 教学提示**：每功能一次、5s 自动隐藏、**全局排队同时只显示一个**（绝不连续轰炸）。
- 每日技巧默认关闭。

### 13.9 无障碍交互要点（补充第 11 章）

- 屏幕阅读器激活时：禁用 Ctrl+Tab 切换器；复选框等仅在 SR 模式下进入 Tab 序。
- 动作的 `text`/`description` 即无障碍名/描述（单一来源，见 12.2）。
- 所有动效可关；高对比度主题圆角归零。

### 14.4 Git 视觉规范（汇总）

1. **文件状态色**（树/标签/变更列表共用）：修改蓝、新增绿、删除灰（+删除线）、未跟踪灰斜体（建议）、冲突红、重命名青（建议）、合并紫。文字色用 14.1 的 `--git-*`（亮暗各一套）。
2. **编辑器 gutter**：左侧 4px 圆角 3 修改条（增/改/删三色，见 `--git-g-*`）；单行变更画三角；旁边可显示 blame。
3. **Blame 色带**：按作者哈希在 16 级渐变（亮 `#A1BEF7→#F7F8FA`、暗 `#2F5194→#22252E`）中取色，文字 `--fg-muted`，当前 HEAD 行文字用默认前景。
4. **当前分支/HEAD**：Log 中当前分支提交行背景亮 `#EDF3FF` / 暗 `#283044`；分支图线条饱和度 0.6。
5. **diff**：增/改/删行背景直接复用 gutter 色的低饱和版本（IDEA 的 diff 与 gutter 同源 `DIFF_INSERTED/MODIFIED/DELETED`）。
6. **提交操作**：主按钮用 accent 实底（唯一的强色彩时刻）；进行中用 spinner（125ms/帧，`--fg-info` 灰）。
7. **可空状态**：无变更时 Git 面板给轻量空状态（h3 + 说明文字 + 主操作），参照编辑器空状态。

### 14.8 Markdown 编辑工作流 UX（源自 markdown 插件的行为合同）

**分屏预览模型**：

- 三模式：仅编辑 / 仅预览 / 分屏，**默认分屏**（编辑|预览并排，比例 50/50，全局共享）。
- **滚动同步**：默认开、仅「编辑 → 预览」单向；按**逻辑行**变化触发（非逐像素）；预览 DOM 每个元素携带源位置属性（`data-src-pos`），滚动时二分定位目标元素并 smooth scroll。
- **更新管线**：文档变更 → **20ms 防抖** → **增量 DOM patch**（只改变化的节点，不整页重载）；图片经本地静态资源服务解析（10s 超时）；预览页面 CSP 锁定、外链点击需确认（防误触/clickjacking）。
- 预览字体 = 编辑器字号 **+0.5**；Ctrl+滚轮按 10% 步进缩放（8–72）并显示「重置字号」气泡；Ctrl+F 在预览内查找。
- 编辑器边界滚动转发：编辑器滚到顶/底后再滚轮，把滚动量转发给预览（建议实现）。

**Live Preview（进阶，可选）**：

- 隐藏 `**`、`*`、`` ` ``、`[]()`、`<>` 等标记；**光标/选区触及处立即显示源码**（规则：遮蔽区永远不能压在光标下）；多光标安全。
- 列表标记按层级渲染为 `•◦▪` 循环；整段仅含图片时行内渲染图片；`---`/setext 下划线渲染为真实分隔线。
- 渲染图片旁的 Backspace 删除换行符而非隐藏源码（防破坏）。

**智能键入规则表**（全部有默认开关）：

| 场景                  | 行为                                          |
| ------------------- | ------------------------------------------- |
| Enter 于列表项          | 空项 = 移除标记或降级；非空 = 延续（继承标记/缩进/复选框，有序列表自动重编号） |
| 连续两次 Enter          | 退出列表                                        |
| Shift+Enter 于列表     | 新起一行不含标记                                    |
| Enter 于表格单元格        | 插入 `<br/>`（不破坏行）                            |
| Shift+Enter 于表格     | 追加与当前样式对齐的新行并移入                             |
| Tab / Shift+Tab 于表格 | 下一/上一单元格（行末回绕到下一行）                          |
| 表格内删除/粘贴/复制行        | 列宽**实时重排**（150ms 刷新）                        |
| 粘贴 URL 且有选区         | 选区包裹为 `[选区](URL)`                           |
| 输入 `]` 于 `[ ]` 之后   | 自动跳过                                        |
| 输入 `@`              | 项目文件路径补全（分段模糊匹配，上限 200 项）                   |
| 链接目标中输入 `#`         | 标题锚点补全                                      |
| 输入 ```              | 代码围栏语言列表补全（含别名，插入后光标落围栏内）                   |

**格式化**（Ctrl+Alt+L）：表格重排（ALIGNED 对齐风格为默认）、引用箭头规范化、标题/块元素前后空行 1、子列表固定缩进、块引用内换行时自动补 `>`；**保存时绝不删除行尾空格**（保护两空格硬换行）；代码围栏内不格式化。

**大纲与导航**：结构视图仅显示标题（按层级嵌套，引用/列表是透明容器直接提升内部标题）；面包屑 = 光标前最近的低级标题链；标题进入 go-to-symbol 索引；**TOC**：生成 `<!-- TOC -->` 注释块（缩进 = 层级×缩进宽），再次执行 = 原地更新；过期 TOC 有检查提示 + 快速修复；单个标题可标记「从 TOC 中省略」；重命名文件或标题时自动更新反向链接与锚点。

**检查**（默认开）：表格缺首尾竖线（警告，修复=补边框）、未解析的文件/标签引用（警告）、列表编号错误、TOC 过期、链接含空格（建议 URL 编码）、front matter 字段校验；**代码围栏内默认不报告问题**（可开）。

**折叠默认值**：front matter 折叠、TOC 折叠、链接目标 >10 字符折叠（Live Preview 关闭时）、表格与代码围栏不折叠。

**图片与文件**：粘贴剪贴板图片 → 保存为文件并插入 `![]()`；拖入图片文件 → 插入相对路径引用；拖入其他文件 → 插入链接；gutter 行标记 + 「配置图片」意图。

**浮动格式工具栏**：选区出现（B / I / S / code / 链接 / 标题级别 / 列表）；在代码块/围栏/HTML 内自动抑制；用户可永久隐藏。

**Front matter**：YAML 区块注入高亮与补全（可挂 JSON Schema 校验字段）。

### 14.9 Git 工作流 UX 清单（编辑器版）

1. **状态可见**：文件树/标签按状态着色（14.1 `--git-*`）+ gutter 修改条 + 状态栏分支与同步态。
2. **行级操作**：gutter 单击 → 迷你 diff 卡（片段 + 查看范围 diff / 复制原内容 / 上一处下一处变更 / 词级高亮开关 / **回滚此行**）。
3. **非模态提交**：右侧 Commit 工具窗；复选框选文件（支持部分文件）；提交信息带历史/模板补全；**Commit 是面板默认按钮**；Amend 开关；「Commit and Push」合并动作；结果走通知。
4. **历史与 blame**：Log 视图并行 diff；annotate 作者色带（渐变取色）+ 最后一提交高亮。
5. **冲突解决**：三栏 + 每冲突可「应用左/右」「用某侧解决」「忽略某侧」「重置决定」；顶部黄色 Banner 汇总剩余冲突数。
6. **安全网**：文档撤销 100 步；Local History 对保存/重命名/commit/update 自动快照，可回滚任意时点；Shelve 暂存未提交改动。
7. **分支**：Ctrl+Shift+` 弹窗（搜索 + 速度搜索、最近分支自动展开、空格收藏、记住尺寸）。
8. **反馈纪律**：进度遵守 300ms 规则与三级模型；结果通知 10s；致命错误走独立红叹号通道。
