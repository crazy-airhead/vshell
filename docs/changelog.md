# 更新记录

vShell 的版本更新记录，新版本在顶部追加。版本号与应用仓库的 git 标签一致。

## 未发布

以下改动已进入 main 分支，随下一版本发布：

- **布局**：整体界面重构为岛屿（Islands）设计语言 —— 画布 + 浮动圆角岛，统一 6px 接缝，浅色 / 深色主题令牌单源同步。
- **修复**：同一连接多次打开不再导致先前终端全部断开（此前超出服务端 sshd `MaxSessions` 上限时，新开标签会误关共享连接，连累已打开的所有终端；现正确区分连接断开与服务端拒绝，后者仅提示原因）。
- **依赖**：Wails v3 升级至 v3.0.0-beta.28。

## v0.1.0 · 2026-10-03

首个发布版本（2026-05-18 开始开发）。

- **连接管理**：分组树形组织、拖拽调整归属；密码 / 私钥 / 交互式三种认证，敏感信息 AES-256-GCM 加密存储；支持导入 `~/.ssh/config` 主机。
- **终端**：基于 xterm.js 的 PTY 终端（xterm-256color），WebGL 渲染、右键菜单复制粘贴、断开后回车即刻重连。
- **SFTP 文件管理**：远端目录树 + 双栏浏览，上传 / 下载 / 删除；从系统文件浏览器拖入上传、拖出下载，实时进度与取消。
- **远程文件编辑**：Monaco Editor 直接编辑远程文件（⌘S 写回服务器），按扩展名识别 40+ 种语言。
- **服务器监控**：CPU / 内存 / 磁盘 / 进程 / 网络全覆盖，ECharts 网卡流量趋势，复用 SSH 连接免重复认证。
- **SSH 密钥管理**：生成（Ed25519 / RSA / ECDSA）、导入、管理密钥对；被连接引用的密钥受删除保护。
- **端口转发**：本地端口转发（SSH 隧道），按连接分组，内置 MySQL / Redis / PostgreSQL 等常用预设。
- **HTTPS 证书管理**：集成 acme.sh 远程签发与续签（Let's Encrypt 等主流 CA、DNS 提供商配置、操作日志持久化）。
- **个性化**：中英双语、浅色 / 深色主题、7 套终端配色。
- **文档站**：VitePress 文档站上线并自动部署 GitHub Pages（2026-09-02）。
