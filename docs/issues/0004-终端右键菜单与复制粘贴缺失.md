# ISSUE-0004 — 终端内容区右键菜单缺失，复制粘贴无实现（疑似只能靠系统快捷键）

> **编号**：0004　**状态**：🔴 未处理　**严重程度**：⚠️ 一般（终端日常核心交互，但不阻断使用）
> **发现日期**：2026-07-20　**相关任务**：终端 / 交互

## 问题描述

在终端内容区域（xterm 容器）上右键，**没有任何右键菜单**弹出；复制、粘贴在代码里**完全没有实现**（无选区复制、无剪贴板粘贴）。用户反馈「右键菜单有时无法激活」，并怀疑「复制粘贴是不是只能用快捷键」。

经排查：右键菜单不是「有时无法激活」，而是**终端内容区压根没有绑定右键菜单**——只有标签页标题（tab 条）上有右键菜单。复制粘贴则连快捷键处理都没写，当前完全依赖系统/浏览器默认行为。

## 复现步骤

1. 连接一台 SSH 服务器，打开终端标签页。
2. 在**终端内容区**（黑色输出区域）点右键。
3. 观察：无任何菜单弹出（标签页标题上右键才有菜单）。
4. 选中一段终端输出，按 `Cmd/Ctrl+C` 或尝试粘贴 `Cmd/Ctrl+V`。
5. 观察：复制/粘贴行为不可靠（xterm 默认会拦截按键，且代码未实现）。

## 期望行为

- 终端内容区右键弹出上下文菜单（复制 / 粘贴 / 全选 / 清屏 等）。
- 选中文本可直接复制到系统剪贴板；粘贴可把系统剪贴板内容写入远端 PTY。
- 至少有一套稳定可用的复制粘贴途径（右键菜单 或 显式快捷键）。

## 实际行为

- 终端内容区右键：无菜单。
- 复制粘贴：代码未实现，仅靠系统默认行为，体验不可靠。

## 影响范围

- 终端日常使用最高频的两类操作（复制输出 / 粘贴命令）。
- 影响所有 SSH 终端会话，是核心交互体验缺失。

## 建议方案（可选）

两个问题同源（终端区域没有任何自定义交互），建议一并处理：

1. **终端内容区右键菜单**：在 `XTerminal.vue` 的 `.xterminal-container` 上绑 `@contextmenu.prevent`，用 Naive UI `NDropdown`（`trigger="manual"` + `x/y`，参考 `TerminalPane.vue` 现有写法）弹出菜单；菜单项按选区状态动态显示（有选区→「复制」、剪贴板非空→「粘贴」、再加「全选」「清屏」）。
2. **复制粘贴实现**：
   - 复制：`term.hasSelection()` / `term.getSelection()` → `navigator.clipboard.writeText()`。
   - 粘贴：`navigator.clipboard.readText()` → `term.paste(data)`（注意粘贴大文本的安全提示，可选）。
3. **快捷键兜底**：在 `useShortcuts.ts` 的 `ShortcutMap` 增加 `copy` / `paste`（如 `Cmd/Ctrl+Shift+C`、`Cmd/Ctrl+Shift+V`），并在 `settings.ts` 给默认值；终端聚焦时由 `attachCustomKeyEventHandler` 拦截处理，避免与 xterm 默认行为冲突。
4. **可选**：启用 `rightClickSelectsWord: true`，让右键自动选中光标下单词，再弹菜单。

> 注意 Wails v3 webview 中 `navigator.clipboard` 的可用性需实测；若不可用，可走后端绑定读写系统剪贴板（需新增 service 方法）。
