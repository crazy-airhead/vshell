# ISSUE-0005 — 私钥认证的连接无法查看所用私钥（哪个密钥文件 / 私钥内容均不可见）

> **编号**：0005　**状态**：🟢 已修复　**严重程度**：⚠️ 一般（凭证可观测性缺失，不阻断连接）
> **发现日期**：2026-09-02　**相关任务**：连接管理 / 密钥管理

## 问题描述

vShell 的一个特性是可以在编辑连接时查看已保存的密码（点钥匙图标回显明文）。但对于**私钥认证**的连接，编辑时既**看不出当时选的是密钥管理里的哪个私钥文件**，也**无法回显已保存的私钥内容 / 私钥口令**——表单只提供「粘贴新私钥」的空输入框。密码能看、私钥不能看，行为不一致，不合理。

## 复现步骤

1. 新建连接，认证方式选「私钥」，密钥来源选「从密钥管理选择」，任选一个托管密钥，保存。
2. 右键该连接 → 编辑。
3. 观察：密钥来源显示为「手动粘贴」（不是当时选的「从密钥管理选择」），私钥输入框为空、占位符「留空保持不变」。
4. 全表单找一遍：没有任何入口能查看该连接绑定的密钥文件名、私钥内容或口令（对比：密码认证的连接有钥匙图标按钮可回显密码）。

## 期望行为

- 编辑私钥认证的连接时，能知道**当时用的是哪个密钥**（至少能还原「从密钥管理选择： xxx」的来源信息）。
- 与密码一致，提供**私钥内容（和口令）的回显入口**，点击查看、再点收起恢复「留空保持不变」语义。

## 实际行为

- 密钥来源被重置为「手动粘贴」，托管密钥的选中项丢失。
- 私钥 / 口令输入框均为空，占位符提示「留空保持不变」，无任何查看途径。
- 后端只有 `GetPassword(id)`，没有私钥 / 口令的对应解密读取方法。

## 影响范围

- 所有私钥认证连接的编辑体验与凭证核对（换密钥、排查认证失败时无法确认当前用的是哪把钥匙）。
- 数据层面：创建时只把私钥**内容**加密拷贝进 `connections.private_key`，**密钥名没有持久化**，来源信息在保存那一刻就丢了。

## 相关文件 / 符号

- `frontend/src/components/sidebar/ConnectionFormModal.vue`
  - L86-101 `watch(props.show)` — 编辑分支把 `privateKey` / `keyPassphrase` 置 `''`、强制 `keySource='manual'`、`selectedKeyName=null`：托管来源信息在此丢失。
  - L209-218 回显按钮 `v-if="form.authType === 'password' || form.authType === 'interactive'"` — 私钥认证无对应按钮。
  - L137-152 `toggleRevealPassword()` — 仅有密码回显逻辑。
  - L246-259 私钥 / 口令表单项 — 只接受新值，placeholder「留空保持不变」。
- `internal/app/app.go`
  - L353-359 `GetPassword(id)` — 只解密回显 `password` 列；无 `GetPrivateKey` / `GetKeyPassphrase`。
- `internal/models/models.go` — `Connection.PrivateKey` / `KeyPassphrase` 均加密存储且 `json:"-"`（不外发，合理）；但**没有字段记录来源密钥名**（如 `key_name`），编辑时无法还原托管选择。

## 建议方案（可选）

1. **私钥 / 口令回显**：后端仿照 `GetPassword` 增加 `GetPrivateKey(id)`（及 `GetKeyPassphrase(id)`，可选）；前端在私钥认证分支加与密码一致的钥匙按钮，点击拉取并回显到 textarea（只读态或可编辑均可），再点清空恢复「留空保持不变」。
2. **来源信息还原（治本）**：`connections` 表增加 `key_name` 列，创建 / 更新时若来自托管密钥则记录；编辑时据此回显「从密钥管理选择： xxx」并预选。存量数据可在编辑打开时按内容（或指纹）匹配 `~/.ssh` 下的密钥推断回填，匹配不到则降级显示「手动粘贴」。
3. 两项可分步落地：回显是纯增量、风险低；`key_name` 涉及迁移（`db/migrations.go`）。
