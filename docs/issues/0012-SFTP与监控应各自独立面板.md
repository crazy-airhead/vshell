# ISSUE-0012 — SFTP 与监控合并在同一面板，应各自独立

> **编号**：0012　**状态**：🟡 进行中（待实机验收）　**严重程度**：💡 体验
> **发现日期**：2026-10-11　**相关任务**：布局重构 / 底部工具窗（岛屿布局）

## 问题描述

新界面（岛屿布局）中，SFTP 与服务器监控被合并到同一个底部工具窗里，以标签页切换显示。两者功能上没有关联，没有必要合并，各自独立面板即可。

## 复现步骤

1. 连接一台服务器；
2. 打开底部工具窗，分别点击「监控」「SFTP」标签；
3. 观察到两者共享同一窗口区域，同一时刻只能显示其一。

## 期望行为

SFTP 与监控各自拥有独立面板（各带标题的工具窗），**互斥显示**——同一时刻至多一个展开，不共用一个标签页容器。

## 实际行为

`MonitorPanel` 与 `SFTPArea` 以 `v-show` 共存于同一个 ToolWindow，靠 `bottomTool` 单值互斥切换；切换标签时另一功能的内容被隐藏。

## 影响范围

底部工具窗布局、监控 / SFTP 使用流程（两者共用一个标签页容器，切换需经标签）。

## 相关文件 / 符号

- `frontend/src/components/shell/AppShell.vue` — **唯一必改**：底部从「单 ToolWindow + `#tabs` 药丸标签 + 双面板 `v-show`」改为两座独立 ToolWindow
- `frontend/src/components/shell/ToolWindow.vue` — `#tabs` 槽随标签页方案废弃（可顺带移除）
- `frontend/src/stores/layout.ts` — `BottomTool` 单值 + `toggleBottomTool` 互斥语义已是目标行为，**无需改动**
- `frontend/src/components/shell/LeftStripe.vue` · `StatusBarIsland.vue` · `monitor/MonitorPanel.vue` · `sftp/SFTPArea.vue` — 均依赖 `bottomTool` 单值（开关高亮 / 传输摘要直达 / 连接全关自动收起 / ECharts 重渲 watch），语义未变，**无需改动**

## 建议方案（可选）

**方案已定（2026-10-11，设计语言同步更新；两工具窗互斥显示，不并排）：**

1. **状态模型**（`stores/layout.ts`）：**不变**——`bottomTool:
   'monitor' | 'sftp' | null` 单值 + `toggleBottomTool`（再点收起、点另一
   工具切换）即目标语义；可见性不持久化（沿现状，启动收起）。
2. **布局**（`AppShell.vue`）：底部从「单 ToolWindow + `#tabs` 药丸标签 +
   双面板 `v-show`」改为「两座 ToolWindow 各自带标题（「服务器监控」/
   「SFTP」），`visible = bottomTool === tool`、常挂载」；`bottomTabs` /
   `selectBottomTab` / `#tabs` 删除，隐藏钮只收自己（`bottomTool = null`）。
3. **尺寸**：坞高共享 `bottomHeight`（80–600，现有横热区不变）；无中缝
   竖热区、无 `bottomSplitWidth`。
4. **联动点**：`bottomTool` 语义未变，左条 / 状态栏开关高亮、传输摘要
   直达 SFTP、连接全关自动收起、ECharts 重渲 watch 均不需改动。
5. **过渡**：切换 = 出岛收起、入岛展开（两岛高度互补过渡，300ms，坞高
   不变）；收起沿负 margin 规则（§3.2-3）。
