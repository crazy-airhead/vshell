# ISSUE-0006 — 密钥管理面板「复制私钥」提示复制失败

> **编号**：0006　**状态**：🟢 已修复　**严重程度**：⚠️ 一般（复制公钥同路径，大概率一并失效）
> **发现日期**：2026-09-02　**相关任务**：密钥管理 / 剪贴板

## 问题描述

在密钥管理面板，右键某个密钥 →「复制私钥」，toast 提示「复制失败」，私钥内容没有进剪贴板。（悬停按钮「复制公钥」走同一条代码路径，预期同样失败。）

## 复现步骤

1. 打开密钥管理面板（至少有一个已保存密钥）。
2. 右键密钥条目 → 「复制私钥」。
3. 观察：toast「复制失败」；到其他应用粘贴，剪贴板里没有私钥内容。

## 期望行为

- 「复制私钥 / 复制公钥」把密钥内容写入系统剪贴板，toast「已复制」。

## 实际行为

- toast「复制失败」，剪贴板无内容。

## 影响范围

- 密钥管理面板的私钥 / 公钥复制（右键菜单 + 悬停按钮，共 3 个入口）。

## 相关文件 / 符号

- `frontend/src/components/keys/KeyManagementPanel.vue`
  - L155-163 `copyKey()` — 直接 `await navigator.clipboard.writeText(content)`。**Wails v3 macOS WKWebView 下 `navigator.clipboard` 不可靠**（0004 已实证并修复过同类问题），此处未迁移；且 `catch` 不区分「读取密钥失败」与「写剪贴板失败」，一律提示「复制失败」，掩盖真实错误。
- `internal/app/app.go` L963-983 `ReadSSHKeyContent(name, kind)` — 后端直接读文件，`kind != "pub"` 即返回私钥，逻辑本身无问题（前端 `'private'` / `'priv'` 两种传法都能命中私钥分支）。
- **参考实现**：`frontend/src/components/terminal/XTerminal.vue` L216-227 `writeClipboard()` — 0004 落地的模式：优先 `@wailsio/runtime` 的 `Clipboard.SetText`，失败回退 `navigator.clipboard`。

## 建议方案（可选）

1. 把 `XTerminal.vue` 的 `writeClipboard()`（`Clipboard.SetText` 优先 + `navigator.clipboard` 兜底）抽成共用工具（如 `frontend/src/utils/clipboard.ts` 或 composable），`copyKey()` 改用之；`XTerminal.vue` 同步替换为共用版本。
2. `copyKey` 的 catch 按阶段区分提示：读取密钥失败（带后端 error）vs 写剪贴板失败，便于以后排查。

## 解决记录

**第 1 轮**（2026-09-02）

- **处理**（按「建议方案」1、2 落地）：
  - `frontend/src/utils/clipboard.ts` — 新建共用工具：`writeClipboard()`（Wails 运行时 `Clipboard.SetText` 优先，失败回退 `navigator.clipboard.writeText`，返回是否成功）与 `readClipboard()`（`Clipboard.Text()` 优先，回退 `navigator.clipboard.readText`，失败返回 `''`）。抽取自 0004 在 `XTerminal.vue` 落地的实现。
  - `frontend/src/components/keys/KeyManagementPanel.vue` — `copyKey()` 改用共用 `writeClipboard()`；读取密钥与写剪贴板分阶段报错：读取失败提示「读取密钥失败： {error}」（带后端错误），写剪贴板失败才提示「复制失败」。
  - `frontend/src/components/terminal/XTerminal.vue` — 删除本地 `writeClipboard` / `readClipboard`，改 import 共用版本（终端复制保持原有的静默降级行为）；`@wailsio/runtime` import 去掉不再使用的 `Clipboard`。
  - `frontend/src/locales/zh-CN.ts` / `en.ts` — `keys` 增加 `readFailed`。
- **校验**：`pnpm typecheck` 0 错；`pnpm build` 通过（仅原有 chunk 体积告警）。
- **验收**（实机通过，2026-09-02 用户确认）：密钥管理复制私钥不再提示「复制失败」，内容可正常粘贴。
