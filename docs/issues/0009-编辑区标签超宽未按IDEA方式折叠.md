# ISSUE-0009 — 编辑区标签超宽时未按 IDEA 方式折叠进下拉菜单

> **编号**：0009　**状态**：🟢 已修复　**严重程度**：💡 体验
> **发现日期**：2026-10-07　**相关任务**：布局重构 / 编辑区标签条

## 问题描述

编辑区（中心岛）的会话/编辑器标签条在打开多个标签、总宽超出编辑区可用宽度时，没有按 IDEA「Hide tabs if they don't fit」的方式把放不下的标签折叠进右端下拉菜单，超出部分被直接裁剪，无法再点击切换。

根因：旧布局的标签条（`terminal/TerminalPane.vue` 内联渲染）从未实现超宽折叠——标签用 `h()` 渲染后横向排布，超出即被容器裁剪，无任何溢出检测与折叠入口。

## 复现步骤（修复前）

1. 打开任意多个终端会话 / 编辑器标签（如 10+ 个远程文件）。
2. 标签总宽超过编辑区宽度。
3. 观察：超出部分标签被裁剪不可见，无下拉入口，无法切换到被裁剪的标签。

## 期望行为（IDEA 语言，设计文档 §4.4）

- 标签保自然宽度不缩水（`flex: 0 0 auto`，单标签 ≤300px，极窄行随行收缩下限 100px）。
- 放不下的标签按 **LRU（激活 → 最近使用 → 原始序）** 折叠隐藏，激活标签恒可见。
- 行右端出现 chevron-down「全部标签」下拉钮，列出被折叠标签（含状态点 / 远近前缀色标 / 脏点），点击即激活并回带显示。
- 标签行滚轮 = 按最近使用序平移可见窗口。
- 面板宽度 / 标签数 / 标题 / 字体变化时自动重算。

## 实际行为（修复前）

标签被 `overflow: hidden` 直接裁剪，无折叠、无下拉，被裁标签不可达。

## 影响范围

- 所有终端会话标签与编辑器标签（SFTP 远程文件、SSH 配置编辑、本地文件）。
- 多标签场景下的核心导航体验。

## 相关文件 / 符号

- `frontend/src/components/shell/EditorTabs.vue` — 新标签条（含超宽折叠）：`measure()` 贪心装入 + LRU 折叠、`hiddenTabOptions()` 下拉选项、`onWheel()` 滚轮平移、逐标签 ResizeObserver 重算。
- `frontend/src/components/shell/EditorIsland.vue` — 中心岛挂载 `<EditorTabs />`。
- `frontend/src/components/terminal/TerminalPane.vue` — 旧标签条（无折叠，随岛屿重构退役）。
