# 端口转发

侧栏第四个图标（分享/分流形状）是端口转发面板：按连接分组的转发规则管理，支持本地端口转发（SSH 隧道）。

---

## 1. 面板结构

规则**按连接分组**折叠展示（`NCollapse`），分组标题为「连接名 · 主机」，右侧显示规则数。每条规则显示：

- 类型标签（本地转发 / 远程转发 / 动态转发）
- 名称、本地 `host:port` → 远程 `host:port`
- 状态标签：**运行中 / 已停止**
- hover 操作：▶ 启动 / ■ 停止、✏️ 编辑、🗑 删除（需确认）

## 2. 添加 / 编辑规则

| 字段 | 说明 |
|------|------|
| 名称 | 如「MySQL 隧道」 |
| 连接 | 下拉选择（显示 `名称 (主机)`） |
| 服务预设 | 选中自动填充地址四项，见下表 |
| 类型 | 本地 / 远程 / 动态 |
| 本地地址 + 本地端口 | 监听端 |
| 远程地址 + 远程端口 | 目标端 |
| 自动启动 | 勾选后保存即启动 |

### 服务预设

| 预设 | 本地 | 远程 |
|------|------|------|
| SSH | 127.0.0.1:2222 | 127.0.0.1:22 |
| HTTP | 8080 | 80 |
| HTTPS | 8443 | 443 |
| MySQL | 3306 | 3306 |
| PostgreSQL | 5432 | 5432 |
| Redis | 6379 | 6379 |
| MongoDB | 27017 | 27017 |

## 3. 运行机制

- **本地转发**：在本地 `net.Listen` 监听，每个入站连接经 SSH 隧道 `Dial` 到远端 `remoteHost:remotePort`，双向拷贝流量
- 启动时若该连接尚无活跃 SSH 客户端（如未开终端），会自动建立**仅供转发**的 SSH 连接
- 停止该连接的最后一条转发规则、且没有终端会话时，空闲的 SSH 连接会被自动回收
- 断开连接（如 `⌘W`）会一并停掉该连接的全部转发

## 4. 当前边界（如实说明）

- **仅「本地转发」已实现**：选择「远程转发」或「动态转发」保存后可以，但**启动时会报错** `forward type not yet supported`
- 规则运行状态无主动推送，界面上靠查询刷新
