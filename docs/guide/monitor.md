# 服务器监控

ActivityBar 底部的活动图表图标打开监控面板（底部区域）。连接建立后**自动开始采集**，断开时自动停止——复用 SSH 连接，无需重复认证，也不在服务器上安装任何代理。

---

## 1. 采集范围与频率

| 指标 | 采集间隔 | 数据源（远端命令） |
|------|----------|--------------------|
| CPU / 内存 / 网络 / 在线时长 | 2s | `/proc/stat`、`/proc/meminfo`、`/proc/net/dev`、`/proc/uptime` |
| 负载 | 5s | `/proc/loadavg` |
| 进程 | 5s | `ps -eo pid,user,%cpu,%mem,rss,args --sort=-%cpu | head -30` |
| 磁盘 | 10s | `df -B1 -x tmpfs -x devtmpfs` |
| 监听端口 / 连接 | 10s | `ss -tlnp`、`ss -tnp state established` |

面板切换的是**当前激活终端标签**所属连接的监控数据；无活动连接时提示「无活动连接」。

## 2. 概览栏（左侧 280px）

自上而下：

| 项目 | 内容 |
|------|------|
| 主机 | 主机名 + 系统类型 + IP 列表（排除 127.0.0.1） |
| 在线时长 | `d h m` 格式 |
| CPU | 总占用进度条 |
| 内存 | 已用 / 总量 |
| 进程 TOP5 | 名称 + CPU% + 内存% |
| 磁盘 | 挂载点汇总 |
| 网络 | ↓ 接收 / ↑ 发送速率 |

**每项都可点击**，右侧详情区随之切换。

## 3. 详情区

| 详情 | 内容 |
|------|------|
| CPU | 每核心独立进度条 |
| 内存 | 物理内存 + 交换区（无 swap 显示「无交换区」） |
| 磁盘 | 每个挂载点：百分比、设备、已用 / 总量 |
| 进程 | 完整表格（PID、CPU、内存、用户、命令、路径），列可排序，命令与路径可一键复制 |
| 网络 | 二级标签「网卡 / 进程」 |

### 网络详情

- **网卡页**：顶部 **ECharts 趋势折线图**（↓RX 蓝 / ↑TX 橙，约 60 个采样点窗口），下方接口表（接收 / 发送速率与累计流量），点击某行切换图表对象
- **进程页**：监听进程表（PID、进程、监听地址、端口、连接数）

## 4. 显示约定

百分比进度条颜色阈值：< 60% 绿色、< 85% 黄色、≥ 85% 红色。

## 5. 实现说明

- 采集通过在既有 SSH 连接上周期性 exec 命令完成（每轮新建 exec 会话），**数据不落库**，面板关闭只是不显示、采集随连接生命周期
- CPU 百分比按 `/proc/stat` 两次采样差值计算（含逐核）；网卡速率按相邻两次 `/proc/net/dev` 差值 ÷ 间隔计算
- 监控指标目前仅支持 Linux（`/proc`、`df`、`ss`）；非 Linux 系统仅显示主机名等基础信息
