# SFTP 文件管理

ActivityBar 底部的文件夹图标打开 SFTP 面板（底部区域），提供远端 / 本地双栏浏览与多种传输方式。面板**跟随当前激活的终端标签**所属连接；连接全部断开时面板自动关闭。

---

## 1. 面板布局

```text
┌───────────────────────────────┬─────────────────────────┐
│ 远端（flex 6）                  │ 本地（flex 4）           │
│ ┌─────────┬─────────────────┐ │ ┌─────────────────────┐ │
│ │ 目录树   │ 面包屑路径条      │ │ │ 面包屑路径条          │ │
│ │（懒加载, │ 名称 大小 修改时间 │ │ │ 名称 大小 修改时间     │ │
│ │ 可拖宽） │ [表头点击排序]     │ │ │ [.*] [刷新] [📂]     │ │
│ │         │ [刷新][⬇][🗑]     │ │ │ [⬆ 上传][🗑]         │ │
│ └─────────┴─────────────────┘ │ └─────────────────────┘ │
├───────────────────────────────┴─────────────────────────┤
│ ▸ 传输状态条（22px）：总进度 · 当前文件 · 合计速度 [✕ 取消] │
└─────────────────────────────────────────────────────────┘
```

- **远端侧**：左侧懒加载目录树（宽 120–500px 可拖）+ 右侧文件表格
- **本地侧**：从主目录开始浏览；`.*` 按钮显示 / 隐藏隐藏文件；📂 在系统文件管理器中打开当前目录
- 双击路径条可变为输入框，手输路径回车跳转；点击面包屑某一级可直达
- 单击选中，`Ctrl / ⌘ + 点击` 多选
- 表头点击排序（目录恒排前，升 / 降序切换）

## 2. 传输的四种方式

| # | 方式 | 操作 |
|---|------|------|
| 1 | 按钮下载 | 选中远端文件 → **⬇ 下载所选**，落到本地侧当前目录 |
| 2 | 按钮上传 | 选中本地文件 → **⬆ 上传所选**，传到远端侧当前目录 |
| 3 | 应用内拖拽 | 本地行拖到远端列表 = 上传；远端行拖到本地列表 = 下载；支持多选拖拽（拖拽幽灵显示 `+N`） |
| 4 | **系统拖入** | 直接从 Finder / 资源管理器把文件拖到远端列表区域上传（原生文件拖放） |

> **反向拖出（远端拖到桌面）不支持**：Wails v3 尚无系统级拖出能力（`docs/issues/0002`，标记不修复）。下载请用方式 1 / 3。

- 删除：远端 / 本地两侧均有 🗑 删除所选；远端目录会递归删除
- 目录传输：上传 / 下载都支持整个目录递归（自动 `MkdirAll`）

## 3. 传输进度与并发

- 底部 22px 常驻状态条：所有任务按字节合计的整体进度、当前文件名、合计速度（KB/s / MB/s）
- 有活动任务时显示 **✕ 取消所有传输**
- 全部完成后 2 秒自动收起
- 后端并发上限 **3 个传输**（超出排队），32KB 块读写
- 传输完成自动刷新对应目录列表

进度数据经 `sftp:progress` 事件实时推送（单文件百分比 / 速度，目录传输按总字量聚合）。

## 4. 与编辑器联动

双击远端文本文件直接进入[远程文件编辑](editor.md)（≤ 5MB、非二进制），无需下载到本地。

## 5. 当前边界（如实说明）

远端文件操作目前支持：**浏览、读取、写入（编辑器）、删除、上传、下载、取消传输**。以下操作暂不支持：

- 新建文件 / 新建目录
- 重命名 / 移动
- 修改权限（chmod）
