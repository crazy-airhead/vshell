# 连接与分组管理

侧栏「连接」面板（ActivityBar 第一个图标）是 vShell 的主入口：分组树 + 连接列表，新建、编辑、双击连接打开终端。

---

## 1. 界面结构

```text
┌─────────────────────────┐
│ 连接      [📁+] [➕]     │  标题栏：新建分组 / 新建连接
├─────────────────────────┤
│ ▾ 生产环境               │  分组（hover：➕ 新建连接 ✏️ 重命名 🗑 删除）
│    ├─ web-01            │  连接（hover：⚡ 连接 ✏️ 编辑 🗑 删除）
│    └─ db-01             │
│ ▾ 测试环境               │
│    └─ test-01           │
│ （未分组连接）            │  未分组的连接排在根级末尾
└─────────────────────────┘
```

- 分组按 `parent_id` 递归构树，默认展开全部
- 连接行显示 `名称` + `主机:端口`
- 侧栏宽度可在 200–500px 间拖拽调整

## 2. 连接的建立与打开

| 操作 | 行为 |
|------|------|
| **双击连接** | 建立 SSH 连接并打开终端标签 |
| 单击连接 | 切换到该连接已存在的第一个终端标签（不新建） |
| hover ⚡ 闪电 | 与双击等价，快速连接 |
| 拖拽连接到分组 | 修改所属分组（`MoveConnection`） |

连接失败时弹出错误对话框，包含后端原始错误与提示「无法连接到 {host}，请检查主机地址、端口和认证信息」。

## 3. 连接表单

点击 ➕ 新建或 ✏️ 编辑打开连接表单（模态，宽 480px）：

| 字段 | 说明 |
|------|------|
| 名称 | 必填 |
| 分组 | 下拉选择，`-` 表示未分组 |
| 主机 | 必填 |
| 端口 | 1–65535，默认 22 |
| 用户名 | 必填 |
| 认证方式 | 密码 / 私钥 / SSH Agent / 交互式 |
| 密码 / 私钥 / 口令 | 依据认证方式显示，保存时 AES-256-GCM 加密入库 |

### 3.1 认证方式

| 认证方式 | 实现状态 |
|----------|----------|
| **密码** | 直接输入密码。编辑时可点钥匙图标回显已存密码（再点一次清空，留空表示保持不变） |
| **私钥** | 见下文「密钥来源」 |
| **SSH Agent** | 表单中可选，但**后端尚未实现**，连接时会报错 `ssh agent auth not yet implemented` |
| **交互式** | Keyboard-Interactive：输入密码，服务器的每个提问都会以该密码应答 |

### 3.2 私钥认证的两种来源

- **从密钥管理选择**：下拉列出[密钥管理](keys.md)中的密钥（`名称 (类型 - 注释)`，可搜索），选中后自动读取私钥内容；若该密钥有口令，会提示「该密钥有密码保护，请输入密钥口令」
- **手动粘贴**：textarea 粘贴私钥内容。编辑时可用钥匙图标回显已存私钥，回显后自动与 `~/.ssh` 中管理的密钥逐个比对，提示「与密钥管理中的「xx」内容一致」或「与密钥管理中的任何密钥都不匹配」

编辑已有连接时，若其私钥仍存在于密钥管理，会自动还原为「从密钥管理选择」模式。

### 3.3 校验

保存前校验（`message.warning` 提示）：名称非空、主机非空、新建时私钥认证必须提供私钥内容。

## 4. 分组操作

| 操作 | 说明 |
|------|------|
| 新建分组 | 标题栏 📁+ 按钮创建根分组 |
| 重命名 | hover 分组行点 ✏️ |
| 删除 | hover 点 🗑；**组内有连接时会被拒绝**，提示先将连接移出 |
| 移动连接 | 拖拽连接到目标分组；也可以拖到某连接的前后调整排序 |

> 数据模型支持分组嵌套（`parent_id`），当前界面仅提供根分组的创建入口；分组本身不可拖拽。

## 5. 删除连接与联动清理

- 删除连接需确认；后端会先断开该连接的 SSH 会话，再删除记录
- 关闭某连接的最后一个终端标签时，会同时关闭其 SFTP 面板；`⌘W`（File → Close）则**断开整条连接**（含监控）并关闭标签，详见[终端使用](terminal.md)

## 6. 数据与安全

- 连接存储在本地 SQLite（见[数据存储与加密](../dev/storage-crypto.md)）
- `password` / `private_key` / `key_passphrase` 三列只存 AES-256-GCM 密文；连接列表查询**不返回**这三个字段，需要时通过 `GetPassword` / `GetPrivateKey` / `GetKeyPassphrase` 单独解密读取（用于表单回显）
