# SSH 密钥管理

侧栏「密钥」面板（ActivityBar 第二个图标）直接管理 `~/.ssh` 目录下的密钥对：生成、粘贴导入、复制、重命名、删除。

---

## 1. 密钥列表

列表读取 `~/.ssh` 下的私钥文件（递归扫描，跳过 `.pub`、证书、`known_hosts`、`authorized_keys` 等非私钥文件），每条显示：

| 信息 | 说明 |
|------|------|
| 类型徽章 | RSA / Ed25519 / ECDSA / DSA（按公钥算法） |
| 文件名 | 相对 `~/.ssh` 的路径 |
| 指纹 | 公钥指纹 |
| 注释 | 公钥尾部的 comment（通常 `user@host`） |
| 🔒 锁图标 | 该私钥有口令保护 |

`~/.ssh` 中没有密钥时显示「未在 ~/.ssh 中找到 SSH 密钥」。工具栏三个按钮：**刷新**、**生成密钥**、**新建密钥**（粘贴导入）。

## 2. 生成密钥

| 字段 | 说明 |
|------|------|
| 密钥类型 | Ed25519 / RSA / ECDSA |
| 强度 | RSA：2048 / 3072 / 4096；ECDSA：256 / 384 / 521（Ed25519 无此项） |
| 文件名 | 切换类型时自动给出默认名（`id_ed25519` / `id_rsa` / `id_ecdsa`） |
| 注释 | 可选，占位提示 `user@host` |
| 密钥口令 | 可选，为私钥加口令 |

生成结果：私钥写入 `~/.ssh/<文件名>`（权限 0600），公钥写入 `~/.ssh/<文件名>.pub`（0644）。

> RSA 强度低于 2048 时后端强制使用 4096。

## 3. 粘贴导入（新建密钥）

填写文件名（必填）+ 粘贴私钥内容（必填）+ 公钥内容（可选），保存即写入 `~/.ssh`。适合把已有密钥从别处迁移进来。

## 4. 密钥操作

| 操作 | 入口 | 说明 |
|------|------|------|
| 复制公钥 | hover 快捷按钮 / 右键菜单 | 复制 `.pub` 内容，适合添加到服务器 `authorized_keys` |
| 复制私钥 | 右键菜单 | 复制私钥内容 |
| 重命名 | hover 快捷按钮 / 右键菜单 | 连带重命名 `.pub` 文件 |
| 删除 | hover 快捷按钮 / 右键菜单 | 见下文删除保护 |

复制走 Wails 运行时剪贴板（WKWebView 下浏览器剪贴板 API 不可靠，失败时自动回退）。

## 5. 删除保护

删除前会检查密钥是否被连接引用——除按 `key_name` 关联外，还会**解密各连接的私钥内容逐字节比对**。被引用时拒绝删除并提示：

> 密钥 "xxx" 正被以下连接使用：…，无法删除

避免删掉密钥后连接全部失效（问题记录见 `docs/issues/0007`）。

## 6. 与连接的关系

[连接表单](connections.md)选择私钥认证时，「从密钥管理选择」下拉列出的就是这里的密钥；连接记录会保存 `key_name`，密钥有口令时在表单中单独输入口令。

密钥文件本身不受数据库加密体系管理（它就是 `~/.ssh` 里的普通文件）；存入连接的私钥**内容**才会 AES-256-GCM 加密后进数据库，详见[数据存储与加密](../dev/storage-crypto.md)。
