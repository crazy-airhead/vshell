# 终端使用

vShell 的终端基于 [xterm.js v6](https://xtermjs.org/)，每个会话一个完整的 PTY 终端（`xterm-256color`），以标签页组织。

---

## 1. 标签页

主区右侧为标签页式终端区（`NTabs` 卡片风格）：

- 标签标题左侧的状态点：**绿色 = 已连接**，灰色 = 已断开
- 编辑器标签（[远程文件编辑](editor.md)）与终端标签混排，带 `[远端]` / `[本地]` 前缀；未保存时标题后出现橙色 `•`，悬停显示完整路径
- 标签内容常驻内存（隐藏而非销毁），切换标签不丢终端状态

### 标签右键菜单

| 菜单项 | 说明 |
|--------|------|
| 复制会话 | 基于同一连接再开一个终端会话 |
| 重新连接 | 仅断开态可用 |
| 断开连接 | 仅连接态可用 |
| 关闭 / 关闭其他 / 关闭所有 | 批量关闭 |

### 关闭的两种语义

| 入口 | 行为 |
|------|------|
| 标签 ✕ / 右键菜单 | 只断开**该会话**；若这是所属连接的最后一个终端，同时关闭其 SFTP 面板 |
| `⌘W`（File → Close） | **断开整条连接**（全部会话 + 监控 + SFTP）并关闭标签 |

## 2. 终端交互

| 操作 | 行为 |
|------|------|
| 右键 | 先选中光标处单词，再弹出菜单：**复制 / 粘贴 / 全选 / 清屏** |
| 复制 | 有选区时可用；快捷键见下表 |
| 粘贴 | 粘贴到终端（`term.paste`） |
| 断线后按回车 | **立即重连**：显示「正在重连...」，成功后原标签接续新会话；失败显示「重连失败，按回车键重试」 |
| 双击标题栏 | 窗口最大化 / 还原 |

断开时终端内显示黄色提示行 `--- 连接已断开，按回车键重连 ---`。

### 复制粘贴快捷键

| 平台 | 复制 | 粘贴 |
|------|------|------|
| macOS | `⌘C`（有选区时） | `⌘V` |
| Windows / Linux | `Ctrl+Shift+C` | `Ctrl+Shift+V` |

快捷键可在[设置](settings.md)中自定义。

**终端内 `Ctrl+C` / `Ctrl+V` 永远透传给远端**（SIGINT / quoted-insert 语义），不会被应用截走——这是有意设计。

### 剪贴板实现

复制 / 粘贴优先走 Wails 运行时剪贴板（macOS WKWebView 下 `navigator.clipboard` 不可靠），失败时自动回退浏览器 API（问题记录见 `docs/issues/0004`）。

## 3. 渲染与配色

- **WebGL 渲染**（WebglAddon），不支持时自动回退 canvas 渲染
- 光标闪烁开启；右键自动选中单词
- **7 套配色**：默认（跟随明暗主题自动切换 dark / light 两套）、Solarized 暗色 / 浅色、Dracula、Monokai、One Dark，在[设置 → 终端](settings.md)中选择，实时生效
- 终端字体（Menlo / JetBrains Mono / Fira Code 等）与字号（10–24）同样在设置中调整，实时生效

## 4. 窗口尺寸与 PTY

- 会话建立时以 24 行 × 80 列请求 PTY，随后按窗口实际尺寸 `WindowChange` 跟随调整
- 侧栏拖宽 / 窗口缩放时终端自动重新 fit

## 5. 当前边界（如实说明）

- **终端内搜索（Ctrl+F）未提供**
- **分屏未提供**（单标签单终端）
- `⌘W` 会断开整条连接（含其他终端会话），关闭单个标签请用标签 ✕
