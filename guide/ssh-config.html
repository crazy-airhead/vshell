~/.ssh/config 导入导出 ​

侧栏「SSH 配置」面板（ActivityBar 第三个图标）直接管理 ~/.ssh/config：结构化编辑主机条目，或把主机一键导入为 vShell 连接。

1. 面板结构 ​

工具栏四个按钮：刷新、编辑源文件、添加主机、导入为连接。

主机条目以折叠卡片列表展示：

text
┌──────────────────────────────────┐
│ [Host] web-prod   user@1.2.3.4:22 │  折叠态：徽章 + 别名 + 元信息
│   （hover：✏️ 编辑  🗑 删除）        │
└──────────────────────────────────┘

展开后是结构化编辑表单。

2. 结构化编辑 ​

每个条目对应 config 中一个 Host（或 Match）块：

字段对应指令
主机别名Host
主机名HostName
用户名User
端口Port
密钥文件IdentityFile
额外配置项任意键值对，可增删（如 ServerAliveInterval 60）

保存时以结构化形式整文件重写（缩进指令、块间空行、0600 权限）。删除主机需确认。

解析器为扁平键值模型：支持 Host / Match 块内的大小写不敏感指令；不支持 = 分隔符、Include 展开与 Match 条件求值。复杂配置建议用「编辑源文件」。

3. 编辑源文件 ​

以编辑器标签打开 ~/.ssh/config 原文（标题即文件路径），用 Monaco 直接编辑，⌘S 保存整文件覆写。适合手工微调注释、复杂指令等结构化表单覆盖不到的内容（详见远程文件编辑）。

4. 导入为连接 ​

点击「导入为连接」后：

  1. 列出全部候选主机：别名、host:port、用户、密钥文件，并用 绿√ / 红✕ 标记 IdentityFile 是否存在
  2. 勾选需要的主机（支持全选 / 取消全选）
  3. 两种导入方式：
方式行为
添加连接取第一个选中项读取详情（含私钥内容）预填连接表单，确认后才创建；有私钥时认证方式自动置为「私钥」
直接导入 (N)批量创建连接，成功提示「已导入 N 个连接」

导入规则：

  • 连接名 = Host 别名；HostName / Port（默认 22）/ User 缺省时按默认值兜底
  • IdentityFile 可读时：认证方式为私钥，私钥内容加密入库；文件位于 ~/.ssh 内时同时记录密钥名，之后在连接表单中会显示为「从密钥管理选择」
  • 无 IdentityFile 时：认证方式为密码（留空，连接前补填）

5. 与其他功能的关系 ​

  • 导入的连接和其他连接一样进入连接管理树
  • IdentityFile 指向的密钥出现在密钥管理列表中即可被引用（支持 ~/ 前缀、绝对路径与 ~/.ssh/ 相对路径解析）
  • 「导出」即对 ~/.ssh/config 的读写能力（结构化重写 / 原文覆写）；当前没有「把 vShell 连接导出回 config」的功能
